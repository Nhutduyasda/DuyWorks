# Phase 5 — Production Polish & SEO

## Goal

Prepare the website for public launch.

---

## Scope

Review and improve:

- SEO
- metadata
- Open Graph
- favicon/app icons
- semantic HTML
- accessibility
- responsiveness
- performance
- image optimization
- content quality
- link integrity
- production build quality

---

## SEO

Verify:

- page titles
- descriptions
- canonical strategy if needed
- semantic heading hierarchy
- Open Graph
- social sharing previews
- sitemap if appropriate
- robots configuration if appropriate

---

## Accessibility

Review:

- keyboard navigation
- focus indicators
- semantic elements
- labels
- contrast
- alt text
- accordion behavior
- mobile menu behavior

---

## Performance

Review:

- image sizes
- Next.js Image usage
- font loading
- unnecessary Client Components
- heavy JavaScript
- unused dependencies
- layout shift

---

## Content Review

Check:

- no Lorem Ipsum
- no placeholders accidentally left public
- no fake claims
- no confidential project data
- no broken social/contact links
- consistent Vietnamese copywriting

---

## Final QA

Run all checks in:

`docs/agent/QA_CHECKLIST.md`

The project must not be considered launch-ready until mandatory checks pass.

---

## Exit Condition

Website is production-ready and suitable for public sharing.
