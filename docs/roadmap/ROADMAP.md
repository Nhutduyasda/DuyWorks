# Product Roadmap

## Phase 1 — Foundation & Home

### Goal

Establish the complete visual language and finish the Home page.

### Scope

- project foundation
- design system
- global layout
- navigation
- Home
- footer
- Zalo CTA
- responsive baseline
- initial project/service data architecture

### Exit Condition

Home feels production-ready before building the remaining public pages.

---

## Phase 2 — Services

### Goal

Present available development services clearly.

### Deliverables

- `/services`
- `/services/[slug]`
- service data architecture
- service CTA
- service FAQ
- related project references

### Exit Condition

A potential client can understand what each service solves and how to contact the developer.

---

## Phase 3 — Projects & Case Studies

### Goal

Turn real development work into trust-building proof.

### Deliverables

- `/projects`
- client-side filtering
- `/projects/[slug]`
- project gallery
- problem
- solution
- key features
- stack
- qualitative outcome
- project CTA

### Constraint

No fake metrics.

---

## Phase 4 — About & Contact

### Goal

Help visitors understand who is behind the work and contact easily.

### Deliverables

- `/about`
- `/contact`
- Zalo
- email
- LinkedIn
- GitHub
- contact UX

---

## Phase 5 — Production Polish

### Goal

Prepare the website for public use.

### Deliverables

- SEO
- metadata
- Open Graph
- accessibility review
- responsive polish
- performance review
- image optimization
- content review
- final QA

---

## Future Phases

Possible future improvements:

- English localization
- blog / knowledge content
- lightweight CMS
- analytics
- inquiry form backend

These are NOT part of the initial roadmap and must not be implemented without explicit approval.
