# Project Context

## Project Type

Public-facing technology service website.

The website represents an independent developer offering:

- Website development
- Web application development
- Internal management software
- AI integration
- Automation solutions

---

## Primary Business Goal

The website should help potential clients:

1. Understand available services
2. View real projects
3. Understand development capabilities
4. Build trust
5. Contact the developer through Zalo

Primary conversion:

**Contact via Zalo**

---

## Product Definition

This product is:

**Technology Service Website + Developer Portfolio + Project Showcase**

---

## What This Product Is NOT

This is NOT:

- an admin dashboard
- a CRM
- a SaaS dashboard
- a traditional developer CV website
- an e-commerce store
- an AI account marketplace
- a project management system

---

## Target Visitors

Potential clients such as:

- individuals
- small businesses
- shops
- SMEs
- people needing custom software
- businesses needing internal tools
- businesses interested in AI automation

Visitors may not have strong technical knowledge.

Content must therefore remain easy to understand.

---

## UX Goal

A visitor should quickly understand:

- What does this developer build?
- What projects has he built?
- Can he solve my problem?
- How can I contact him?

---

## Primary CTA

**Trao đổi qua Zalo**

---

## Expected Technology Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- Framer Motion only where appropriate

Deployment target:

- Vercel

---

## Language

Primary language:

- Vietnamese

Architecture should not block future English localization.

---

## Content Integrity

Never invent:

- clients
- testimonials
- company names
- ratings
- revenue
- project metrics
- user counts
- business performance claims

If information is unknown, use neutral placeholders or omit it.
